5 Backend Features:

1. JWT Authentication & Authorization – Uses Better Auth JWKS and JWT verification to protect private API routes and identify authenticated users.

2. Event CRUD Operations – Allows authenticated users to create, view, update, and delete their own community events.

3. Event Registration System – Users can join upcoming events, store their registration details, view joined events, and cancel registrations.

4. Personalized Event Management – Fetches events and registrations based on the logged-in user's email, keeping user-specific data separate.

5. Completed Events Gallery API – Retrieves completed events from MongoDB and provides details such as title, image, location, date, and completion message
